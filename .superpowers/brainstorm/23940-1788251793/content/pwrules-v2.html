A is my recommendation, and it is the only one that costs literally nothing. The label row is already there with dead space on its right, and the reserved message line is already there because rule 1's no-shift fix put it there. So the requirement is stated before you type, and the same line that would have shown "Enter a valid email address" instead shows "Needs a number" — one row doing three jobs (hint, progress, error) rather than a new block doing one.

B is the compromise if you want each rule to visibly tick. C is tempting because it is free, but a popover that only appears on focus means the rule is invisible to someone scanning the form, and it collides with password-manager dropdowns in the same position.
