Rename from the kebab, and delete through a real view transition

No invented buttons — both flows start from the row's own three-dot menu, which is what ships. Rename puts the row into edit mode in place and the board title slides. Delete the open board with the toggle off, then on, and compare.

    Hover a row → three dots → Rename board or Delete board. Enter commits a rename, Esc cancels.
