The rule this enforces: a column shows skeleton or content, never both. Each column's skeleton fades out first and its content only begins once that column's skeleton has reached zero — so there is no frame where a real card is painted over a placeholder. The stagger still happens, but between columns rather than through them, which is also more honest: it says "this column has arrived," not "everything is arriving vaguely."

The rising translate is gone too. It was the other half of the ghosting: content offset 8px from the skeleton it replaced meant the two never lined up, so the overlap read as a double image rather than a swap.
