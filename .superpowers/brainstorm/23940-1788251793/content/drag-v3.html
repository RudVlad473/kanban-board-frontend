What is genuinely already good
  • Neighbours already animate — useSortable's default transition is passed through, so the reflow is not a jump today
  • There is a real insertion bar, drawn in the gutter so it does not wait on reflow
  • Motion is dropped entirely under prefers-reduced-motion, not merely shortened
  • The keyboard drag path is carefully built — better than most kanban apps ship
The four things that change
  • DragOverlay. The card leaves the list and is carried above it — scale 1.03, a 1.6° tilt, a real shadow. Today it stays in place at 50% opacity, so you appear to be smearing a copy rather than holding a card
  • The source slot collapses to a dashed ghost instead of the card simply becoming translucent, so the column visibly makes room
  • The drop settles — scale and tilt release over ~160ms on a decelerate curve, rather than the transform snapping. This is the single biggest one
  • The landing is confirmed by a brief ring, which is also where the pending-PATCH state will live — screen 3
