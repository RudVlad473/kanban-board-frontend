The ghost column is 210px of board, permanently, for a rare action

And on a wide board it is also unreachable — it sits after the last column, so adding a column to a twelve-column board means scrolling to the end first. Every candidate below fixes both, except the one that ships.

Insert-between is deliberately absent. createColumnInputSchema takes { boardId, name, color } and the optimistic write appends at columns.length — the API can only append, so a “+” between two columns would need a create followed by a reorder, which is a compound operation with its own failure mode.
