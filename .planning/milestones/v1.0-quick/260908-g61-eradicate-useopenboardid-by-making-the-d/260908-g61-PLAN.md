<objective>
Delete `use-open-board-id.ts` by removing the lag it compensates for: move the board-delete path's
URL change onto `window.history.replaceState`, which Next 16's App Router documents as integrating
with its own router and synchronously updating `usePathname()` with no RSC request.

Purpose: 260907-q83 shipped a correct fix for a real bug, but it is a compensator — a second source
of truth for "which board is open", read out of TanStack's mutation cache, that every future reader
must know to use. Removing the lag removes the need for the compensator entirely.

Output: one URL primitive on the delete path, two call sites reading the pathname directly, one
fewer hook, and the same e2e regression gate still green.
</objective>
