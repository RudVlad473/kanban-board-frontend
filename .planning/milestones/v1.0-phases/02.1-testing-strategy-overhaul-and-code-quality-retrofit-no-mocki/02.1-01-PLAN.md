<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → RSC render | An unauthenticated or session-forged request reaches `app/(dashboard)/layout.tsx` and its nested `SidebarBoards` server component |
| Next.js server → external API | `externalApi.GET` sends a session-derived `userId` and a bridged `JSESSIONID` to the deployed nonprod backend |
| external API → Next.js server | An untrusted, all-optional-typed JSON payload lands in `loadBoards()` before anything renders it |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02.1-01 | Spoofing | `loadBoards()` `userId` argument | high | mitigate | `userId` is read only from `verifySession()`'s own record; the function takes no arguments at all, so no caller can supply one. Task 3 test 3 proves a second account's board never appears. |
