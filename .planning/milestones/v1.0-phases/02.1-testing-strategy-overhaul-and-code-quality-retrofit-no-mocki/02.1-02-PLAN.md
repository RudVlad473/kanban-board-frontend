    <behavior>
        - Given a file whose `/** ... */` block contains 26 lines of prose, the checker reports one violation naming the file, the start line, and the run length.
        - Given a file whose longest comment prose run is 3 lines, the checker reports nothing.
        - Block-comment delimiter lines (`/*`, `/**`, `*/`) and bare `*` continuation lines with no prose do not count toward a run's length.
        - A blank line between two comments ends the run — two separate 3-line comments are compliant.
        - A run immediately preceded by a line containing `comment-length-exempt:` is skipped.
        - Files under a configured ignore list (generated output, `node_modules`, `.next`) are never scanned.
        - Exit code is 1 when any violation is found, 0 otherwise.
    </behavior>
