## Decisions Made

- **Backfill-then-point over fabricating a new ADR:** every displaced rationale that had no existing durable home was added as an addendum to the relevant primitive's own plan SUMMARY (01-06, 01-09, 01-17), never a new ADR — matching the plan's explicit instruction that a SUMMARY pointer is the right weight for a single primitive's implementation note.
- **menu.tsx's tabIndex comment reformat:** the checker's `stripDelimiter` logic leaves a non-empty trailing `}` when a JSX comment closes as a bare `*/}` line — meaning a `{/* text ... */}` block whose continuation lines lack a leading `*` is checker-invisible (a blind spot, not real compliance) AND fails the plan's own comment-only-diff grep assertion (which requires every changed line to start with `//`, `*`, or `/*`). Reformatted to a delimiter-on-its-own-line `{/*` / `* text` / `text */}` shape so the content stays genuinely checker-visible (and within the 3-line budget) while every diff line satisfies the grep.
- **sidebar.tsx's stale phase reference:** the plan explicitly named this as stale (referring to plan 02-08's phase, not 02.1) and specified the replacement — a one-line description pointing at `docs/adr/tech/0019` and `02.1-01-SUMMARY.md`, applied verbatim.
- **Full-tree sweep in Task 3 caught two out-of-`<files>`-list violations** (`sidebar.stories.tsx`, `sidebar.test.tsx`) that the plan's own action text anticipated ("run the checker across the whole `src/components` tree to catch anything the earlier plans in this phase left behind") and the acceptance criteria required (`src/components` exiting 0 for the entire tree) — compressed both, pointing at `02.1-01-SUMMARY.md`.
