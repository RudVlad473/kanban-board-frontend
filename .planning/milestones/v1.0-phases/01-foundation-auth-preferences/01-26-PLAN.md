<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| mock backend state → disk | Mock/test state must never leak account data (even fake, seeded data) to a shared OS temp directory other local processes or users on the same machine could read |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-71 | Information Disclosure | Mock account data (including the seeded demo password) persisted unencrypted to a world-readable OS temp file | low | mitigate | The file mirror is removed entirely; the store is in-memory only for the life of the process |
| T-01-72 | Tampering | Two `next dev` processes (or a test run alongside a dev server) reading/writing the same temp file concurrently, corrupting each other's view of the mock store | low | mitigate | Removing the shared file eliminates the cross-process write race entirely |
</threat_model>
