<objective>
Close GC-13: diagnose, live and with a real automated check, why the Button primitive's `isLoading`
spinner reportedly renders static instead of animating — then fix it if (and only if) the diagnostic
finds a genuine defect rather than the accessibility feature working as designed.

Purpose: `button.tsx`'s `isLoading` path (landed by 01-16, already merged) renders a `LoaderCircle`
with `animate-spin motion-reduce:animate-none`. A source-level audit (01-CONTEXT.md GC-13) found
Tailwind's `@keyframes spin`/`animate-spin` utility present and no global animation-disabling
override anywhere in `src/styles/` or `.storybook/` — the strongest lead points at the reviewer's own
OS/browser "reduce motion" setting (which `motion-reduce:` is *designed* to honor), not a defect. But
that lead is not yet confirmed live, and assuming it without proof is exactly the shallow-fix pattern
this round exists to avoid.

Output: a live, automated diagnostic that conclusively distinguishes "environmental, working as
intended" from "genuine CSS/build defect," a permanent regression test either way, and — only if the
diagnostic finds a real defect — a fix at the specific root cause it names.
</objective>

<decisions>
**The investigation must run live, in a real browser, before any fix.** A source-level read already
found no obvious override — that is a lead, not a proof. Task 1 produces a real, automated,
falsifiable check; Task 2 acts strictly on what Task 1 found, not on the lead alone.

**The diagnostic doubles as a permanent regression test.** It asserts the *correct* relationship
between the environment's reduced-motion preference and the spinner's computed animation state in
both directions — not just "does it animate" — so it stays meaningful (and keeps passing) whichever
way the diagnosis lands, and guards against a future regression in either direction.

**If the finding is "working as intended," the resolution is documentation, not a code change to the
animation mechanism itself.** Silently closing the item with no trace of the finding would leave the
next person to hit this exact report re-investigating from zero.
</decisions>
