<objective>
**This is the phase's tracer slice.** Wire ONE column-create path through every layer this phase
touches — ghost column button → Add Column modal → `useCreateColumn` → `createColumnAction` →
upstream POST → `refresh()` → the column appears as a new swimlane — and prove it before any other
column capability is expanded onto it.

Purpose: this is the first time `board-view.tsx` becomes a client container, the first Server Action
against a column endpoint, and the first time the ghost column exists. If any of those three is
architecturally wrong, it is far cheaper to find out here, on one narrow path, than after rename,
delete and reorder have each been built on top of it. The slice is production-quality, not a
prototype: real validation, real session check, real error handling on the one path.

Output: COLUMN-01's happy path plus its generic inline failure branch, end to end.
</objective>
