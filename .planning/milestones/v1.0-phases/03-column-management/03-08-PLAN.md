<objective>
Deliver COLUMN-02 end to end: a kebab on every column header whose `Rename Column` entry opens a
single-field modal, an optimistic rename that shows the new name immediately, and a rollback with a
version-aware error toast when the server refuses.

concurrency actually becomes visible to the user, and where the distinct version-conflict copy the
UI-SPEC requires gets its first branch. It is also where the column header stops being read-only —
the kebab is the first focusable control inside a column, which is what finally ends the
`scrollable-region-focusable` workaround the board view has carried since Phase 2.

Output: COLUMN-02 satisfied, with the header kebab established as a control separate from the drag
handle plan 03-10 will add.

fetch-layer serializer skips it rather than throwing, producing a URL with the literal placeholder
still in it. Nothing in the type system catches this.
