<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → `/api/boards` Route Handler | Untrusted request; may carry an attacker-chosen `userId` query parameter, a forged cookie, or no session at all |
| Next.js server → external Kanban backend | The bridged `JSESSIONID` credential and the server-derived `userId` cross here |
| external backend → Route Handler | The upstream response body is untrusted input — the contract declares every `BoardResponseDTO` field optional and declares no error schema at all |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-32 | Elevation of Privilege | `userId` resolution in `app/api/boards/route.ts` | critical | mitigate | `userId` comes from `verifySession()`'s record and from nowhere else. Task 1's acceptance criteria grep for the absence of any request-derived value in the GET handler, and Task 2 adds a test that sends a `userId` query parameter and asserts the session's own id was used upstream. This is the phase's single most important control (ASVS V4, 02-RESEARCH.md Security Domain). |
| T-02-33 | Spoofing | Unauthenticated access to `/api/boards` | high | mitigate | The handler calls `verifySession()` itself and returns 401 rather than relying on `proxy.ts`'s optimistic guard or on the `(dashboard)` layout — the CVE-2025-29927 proxy-bypass class the DAL comment already names. Asserted by Task 2. |
| T-02-34 | Information Disclosure | Upstream error text forwarded to the browser | medium | mitigate | The 502 branch returns this project's own authored message; the upstream body is never interpolated into the response. Asserted by a Task 2 test case and recorded as a plan prohibition. |
| T-02-35 | Tampering | Unvalidated upstream body forwarded as `Board[]` | medium | mitigate | `isBoardArray` gates the response; a shape mismatch becomes a 502 rather than a malformed payload the client renders. | T-02-36 | Elevation of Privilege | `externalApi` reaching a client bundle through `boards-api.ts` | high | mitigate | `src/features/boards/api/boards-api.ts` imports nothing from `src/lib/server/`; asserted by a grep in Task 1 and structurally by `pnpm build`, which fails at import time on a `server-only` violation (02-RESEARCH.md Pitfall 4). |
| T-02-37 | Information Disclosure | Board names rendered in the sidebar | low | accept | React escapes JSX text nodes and no `dangerouslySetInnerHTML` exists in this codebase; the sidebar row renders the name as a text node only. |
| T-02-38 | Information Disclosure | TanStack Query cache surviving a sign-out on a shared browser | medium | mitigate | Sign-out is a Server Action that redirects, which unmounts the React tree and discards the per-tree `QueryClient` created in `query-client.tsx`'s `useState` — no module-scope cache exists to survive.
