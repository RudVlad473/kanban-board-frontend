<objective>
Move every assertion the three auth Server Action integration tests carried out of the mocked
`next/headers` world and into Playwright e2e running against a real Next.js server, then delete
those three files.

This is the first irreversible step of D-13's full-e2e migration: once these files are gone, the
`next/headers` fake cookie jar stops being the proving ground for authentication behaviour.

Purpose: prove sign-in, sign-up and sign-out cookie/redirect/rejection behaviour through a real
request scope, with no shim, and lose nothing in the move.
Output: an extended `e2e/auth.e2e.spec.ts`, three deleted integration test files, and a coverage
ledger recording where each old assertion went.
</objective>
