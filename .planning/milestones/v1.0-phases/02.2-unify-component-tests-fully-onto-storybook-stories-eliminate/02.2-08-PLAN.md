<objective>
Retire the last three `next/headers` shim consumers: prove the session-bridge and board-isolation
behaviour end-to-end, and rewrite `session.test.ts` as a pure, mock-free JWT-verification test.

This plan closes D-13: after it lands, no file in the repository mocks `next/headers`.

The key enabling fact was verified directly during planning rather than assumed: importing
`next/headers` in the `node` Vitest project works fine with no mock and no alias — only *calling*
`cookies()` needs a request scope. Since `createSessionService(secret).verifyToken(token)` never
calls it, every JWT rejection assertion in `session.test.ts` can be kept verbatim in meaning with
the shim simply deleted.

Purpose: eliminate the shim entirely while keeping every security assertion it carried.
Output: a new `e2e/session-bridge.e2e.spec.ts`, an extended `e2e/boards-list.e2e.spec.ts`, a
mock-free `session.test.ts`, and two deleted integration tests.
</objective>
