## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| hairsplitter's `ingest.yaml` precedence is inverted vs. `/gsd-ingest-docs`'s convention | hairsplitter ranks authority high→low as bigger numbers (tech ADR=100 down to CONTEXT.md=10); `/gsd-ingest-docs`'s manifest convention is the opposite (lower number = higher precedence). Manually inverted when building the discovery list (tech ADR=1, domain ADR=2, CONVENTIONS=3, DEFAULTS=4, CONTEXT=5) — do this again if re-running or extending the ingest. | advisory | Re-derive the inversion by hand each time, or fix it once by rewriting hairsplitter's SKILL.md Phase 5e template to emit the convention `/gsd-ingest-docs` actually expects. |
| ADRs that name another doc by filename in prose create cross-ref cycles | `docs/adr/tech/0005` and `0009` each said "...recorded in `CONVENTIONS.md`" while `CONVENTIONS.md`'s own section headers cite `(docs/adr/tech/0005)`/`(docs/adr/tech/0009)` — a 2-node cycle each, which `/gsd-ingest-docs` treats as a hard BLOCKER (withholds both docs from synthesis) rather than resolving it silently. | advisory | When writing an ADR that references `CONVENTIONS.md` (or vice versa), prefer prose that doesn't literally repeat the other file's name (e.g. "the project's conventions documentation" instead of `` `CONVENTIONS.md` ``) if both directions are likely to be classified as cross-refs. |
| SPEC-classified docs do NOT populate `requirements.md` under `/gsd-ingest-docs`'s type-routing contract | Adding `HIGH-LEVEL-ARCHITECTURE.md` (classified SPEC) did not fix the "0 requirements" problem — its Flow Spine content routed into `constraints.md` as protocol entries instead. Only a PRD-classified document populates `requirements.md`. | blocking | Before routing to `gsd-roadmapper`, always confirm `.planning/intel/requirements.md` (or the synthesizer's own "Requirements: N" summary) is non-empty. If it's empty and real functional requirements exist elsewhere (a Flow Spine, an OpenAPI contract, a PDF spec), author an actual PRD-shaped document (verb-first, `CATEGORY-NN` REQ-IDs, matching `$HOME/.claude/gsd-core/templates/requirements.md`'s exact format) and classify it PRD before proceeding. |

**Do not proceed with `/gsd-plan-phase` or further ingest runs until the "blocking" row above is acknowledged** — it's the reason this session had to author `PRD.md` from scratch mid-ingest.
