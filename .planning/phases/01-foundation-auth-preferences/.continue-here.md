## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Working outside GSD on discovered work | Small UI fixes found via review got fixed via direct conversational edits instead of a gap-closure plan — no PLAN.md, no SUMMARY.md, no per-task atomic commits, no STATE.md tracking. | blocking | Route ANY discovered work (bug, gap, scope addition) through `/gsd-plan-phase 01 --gaps` before editing code, even if it looks small. |
| Storybook static CSF indexing breaks on non-literal meta exports | A `createIntegrationStory(meta)` factory wrapping a story's default export in a function call broke Storybook's story indexer entirely (`pnpm test` failed to even start) — `tsc`/`eslint` both stayed silent about it. | advisory | Every `*.stories.tsx` default export must be a literal object expression. Shared story-level dependencies (providers, global state) belong in `.storybook/preview.tsx`'s own `decorators` array, not a per-file wrapper function. Always verify story-file changes with the real test suite (`pnpm test`), not just `tsc`/`eslint` — those don't catch this class of break. |
| Windows long-path worktree cleanup can silently half-fail | `git worktree remove --force` and even the robocopy-mirror trick can leave a worktree directory behind with a few native `.node`/`.exe` binaries "Access is denied" (held by some other running process) even after `git worktree list` no longer shows it registered. | advisory | Non-blocking — verify with `git worktree list` (should be empty) rather than `ls .claude/worktrees` (may show stale dirs). Retry `cmd /c "rd /s /q \\?\<path>"` later once no build/dev-server/language-service process is running. |

**Severity values:** `blocking` — resuming agent must pass understanding check before proceeding. `advisory` — important context, does not gate resumption.
