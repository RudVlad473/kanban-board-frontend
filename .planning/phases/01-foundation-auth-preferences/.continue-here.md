## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| `worktree.cleanup-wave` blocks on any file deletion | The automated merge helper has a blanket, unconditional safety guard that refuses to merge ANY worktree branch containing file deletions — even fully intentional, plan-declared ones (upstream gsd-core issue #3003, no opt-in flag exists). It reports `cleanup_blocked` / `branch_contains_deletions`. | advisory | Before merging, diff the blocked branch's deleted files against the plan's own `files_modified` frontmatter. If they match, merge manually with `git merge --no-ff <branch> -m "merge: bring <plan> into master (wave <N>)"`, then manually remove the worktree/branch. Do not treat the block itself as evidence something is wrong. |
| `git worktree remove --force` fails with "Filename too long" on Windows | Nested `node_modules` paths inside `.claude/worktrees/agent-*` exceed the Windows 260-char MAX_PATH limit, so git's own removal silently fails even though `git worktree prune` still clears the registration. | advisory | Use the robocopy-mirror-empty-directory trick (PowerShell): mirror an empty temp dir onto the target with `robocopy $empty $target /MIR ...`, then `Remove-Item -Recurse -Force`. Exit code 2 from robocopy is normal success (extra files removed), not a failure — verify with `Test-Path` afterward, don't trust the reported exit code. |
| IDE diagnostics on worktree files lag reality | The IDE's TS language server reports stale "Cannot find module" / type-mismatch errors against worktree paths that were already fixed, merged, or deleted — sometimes for files that no longer exist on disk. | advisory | Never trust a diagnostic against a `.claude/worktrees/...` path at face value. Verify independently with `pnpm exec tsc --noEmit` run directly in the relevant tree (worktree pre-merge, or main tree post-merge) before treating it as real. |

**Severity values:** `blocking` — resuming agent must pass understanding check before proceeding. `advisory` — important context, does not gate resumption.
