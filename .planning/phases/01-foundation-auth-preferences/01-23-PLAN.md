<decisions>
**`isLoading` composes into `Field.Root`'s existing `disabled` prop, not into `Checkbox.Root`
directly.** Checkbox's current `isDisabled` already flows through `Field.Root`'s `disabled` prop
(D-15's single-propagation-point pattern) rather than being passed to `Checkbox.Root` a second time.
`isLoading` joins that same expression (`disabled={isDisabled || isLoading}` on `Field.Root`) rather
than adding a second, parallel `disabled` prop on `Checkbox.Root` — one source of the disabled state,
matching how this primitive already works, not how Button/IconButton (which have no `Field.Root`)
happen to be wired.

**No spinner glyph.** Every other primitive gaining `isLoading` in GC-01 has an icon slot (Button's
children area, IconButton's glyph, Dropdown's chevron) a spinner can swap into. Checkbox's tick box
is 16-24px (D-18) with no equivalent slot, and the user's own words ("grayed out") describe an
opacity treatment, not a spinner. `checkboxVariants`'s existing `disabled:opacity-50
disabled:cursor-not-allowed` base classes already deliver that the moment `Checkbox.Root` receives
the composed disabled state — no new opacity class is needed, only the new `isBusy` axis for the
cursor.
</decisions>
