## Decisions Made
- **`@/test-utils/index` over bare `@/test-utils`:** the plan's own action text flagged this as an open question to confirm, not assume. `vitest.config.ts` derives its Vite/Vitest aliases from `tsconfig.json`'s `paths` the same way `tsc` resolves imports, but `tsc` additionally requires an exact-or-wildcard path-mapping match — `tsconfig.json` only has `"@/test-utils/*": ["./src/test-utils/*"]`, no bare `"@/test-utils"` key, so `tsc` cannot resolve the bare specifier even though Vite's directory-index resolution can. Recorded per the plan's explicit instruction to note which form was needed.
- **`renderToggle` simplified to drop `initialTheme`:** the original signature threaded both `initialTheme` and `isAuthenticated` through to a bare `<ThemeToggle />`. Every deep test in the file stages the light theme, so after switching to rendering the composed `Light` story (which already supplies `initialTheme: LIGHT`), keeping an unused `initialTheme` parameter would have been dead surface — dropped it and updated all five call sites to pass only `{ isAuthenticated }`.
