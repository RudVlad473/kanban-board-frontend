- No file-local cleanup was reintroduced anywhere in this batch. ## Issues Encountered
- An early exploratory run of `pnpm test:browser -- src/components/ui/dropdown/dropdown.test.tsx src/components/ui/menu/menu.test.tsx` (before the file-scoping issue was diagnosed) unexpectedly ran the entire 20-file browser project instead of just the two named files — `pnpm`'s script-arg-forwarding inserts a literal `--` before the extra args, which `vitest`'s CLI did not honor as a file filter in this invocation shape. That run surfaced one flaky failure in `toast.test.tsx` (a `locator.hover()` timeout, pre-existing/not-yet-converted `.run()`-based test at the time), unrelated to this plan's own edits. Switched to invoking `node_modules/.bin/vitest run --project browser <files>` directly for every subsequent scoped/flake-check/batch-gate run in this plan, which correctly scoped to the requested files each time; no further flake was observed, including in the whole-project batch gate that included `toast.test.tsx` after its own conversion.
