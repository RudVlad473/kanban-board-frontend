## Sampling Rate

- **After every task commit:** the relevant project's quick command — `pnpm test:unit` for hooks/schemas, `pnpm test:browser` for components, `pnpm exec vitest run --project node` for Server Action tests
- **After every plan wave:** `pnpm test` (all Vitest projects) + `pnpm lint` + `pnpm format:check`
- **Before `/gsd-verify-work`:** `pnpm test:all` (full Vitest + full Playwright) green, plus `pnpm build` green
- **Max feedback latency:** ~60 seconds (quick command)
