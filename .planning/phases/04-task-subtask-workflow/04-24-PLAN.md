## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| unpkg.com → the browser under test | Third-party JavaScript is fetched at runtime and executed before every page script |
| local green → phase sign-off | A 20-gate local run has already been red on CI once in this phase; local green is weaker by design |
| seeded accounts → the shared nonprod backend | Every e2e run creates real, permanent rows nobody wipes on a schedule |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-50 | Tampering | CDN-fetched `react-scan` bundle | medium | mitigate | The URL pins an exact version so the fetched bytes cannot change under a green suite; the fixture is opt-in and is never destructured by the standing spec, so no push or CI run executes it |
| T-04-51 | Elevation of Privilege | third-party script running in the app's origin | medium | accept | It runs only in a Playwright-driven browser against a local `next start`, never in production or in a user's browser; the app bundle is provably unchanged because the library is absent from `package.json` and `pnpm-lock.yaml` |
| T-04-52 | Repudiation | an injection that silently instruments nothing | high | mitigate | Inline content via `addInitScript` rather than an appended tag, so it cannot lose the race with React's own chunks; attachment is proved by reading back a library-installed global, with the name determined empirically |
| T-04-53 | Repudiation | claiming the phase closes on local green | high | mitigate | `gh run watch --exit-status` blocks on a real run and each of the four jobs' conclusions is recorded by name |
| T-04-54 | Tampering | accounts left on the shared backend | medium | mitigate | `ls -A .e2e-seeded-users/` asserted empty; every manual cleanup scoped with `--users <id>` |
| T-04-SC | Tampering | package-manager installs | low | accept | This plan installs nothing; `react-scan` is deliberately not a dependency, asserted by a grep of `package.json` and `pnpm-lock.yaml` in task 1's verify block |
