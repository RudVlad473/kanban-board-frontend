## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|----------------------|
| Reporting CI green before it is | Claimed green twice; `quality` failed on a comment-length check, then `e2e` failed on three specs. | blocking | Report only the four job conclusions read back from `gh run view --json jobs`, after `gh run watch` returns. |
| Merging an agent's branch on its own test run | Track B ran its files green; `comments:check` (a CI gate it never ran) turned CI red on top. | blocking | Every agent runs the WHOLE suite plus the full gate list derived from `.github/workflows` — the pre-commit hook runs 2 of 11. Re-run both over the MERGED result. |
| Scoping an agent because a credential "cannot" reach a worktree | Track B was told to skip the full suite for want of `.env.local`; a wrapper made the copy available minutes later. | advisory | `~/.claude/bin/seed-worktree-env <repo> <worktree>` copies it. `cp` itself is denied and NO allow rule can override the deny. |
| Appending `echo "EXIT=$?"` after the command you care about | The wrapper reports the echo's status, so a failure reads as success. | advisory | Let the real command be the last thing in the script. |
| Leaving a dev server running long past its purpose | A `next dev` ran 45 minutes after the verification it was for; backgrounded runs have NO timeout. | advisory | State the expected duration when launching, and stop it by port when the check is done. |
| Forgetting `comments:check` before pushing | Failed three separate CI runs in one session, each costing a red run plus the skipped `visual`/`e2e` behind it. | advisory | Now enforced by the pre-commit hook (`lint-staged.config.mjs`). Two adjacent `/* */` blocks count as ONE — separate them or the count merges. |
