## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|----------------------|
| Orphaned executor branch | GSD executor worktree branches are local-only and self-delete with their worktree, so unmerged task commits vanish at a session boundary. Recurred this session: `worktree-agent-ae6e78084fa8fe8f8` still held the *finished* 04-12 task 3 while the phase branch had only a narrower fix plus 5 skipped tests. | blocking | `git worktree list` at session start, and check `git log <phase-branch>..<worktree-branch>` for every listed agent worktree BEFORE dispatching anything. Push the phase branch after each plan so nothing lives only locally. Both are now done; no worktrees remain. |
| Silent visual-regression no-op | `playwright.config.ts` sets `ignoreSnapshots: !process.env.CI`, so an off-CI `--project visual` run executes every spec, asserts nothing, and reports green. | advisory | Always prefix `CI=1`. To re-record, `--update-snapshots=all` (not `changed`, which skips diffs under the per-pixel threshold). |
| Mock DPI divisor in CLAUDE.md is wrong | CLAUDE.md documents 600 DPI ÷ 6.25 for mock measurement. That is the bug that produced the whole bad radius scale — it over-reads by 1.333x. | advisory | The mock is a **1440 CSS px wide** design: at 600 DPI divide by **8.3333**. Confirmed on two pages independently (p1's Button Primary (L) is 400px tall against a 48px design height; p4's task card is 2332px wide against a 280px design width). CLAUDE.md itself has NOT been corrected — doing so is a loose end. |
| Playwright `dragTo` cannot start a dnd-kit drag | A single press-move-release never clears MouseSensor's activation distance; the card drops back at its origin and the run looks like a product bug. | advisory | Drive `page.mouse.down()` → ~25 interpolated `page.mouse.move()` steps → `page.mouse.up()` via `browser_run_code_unsafe`.
