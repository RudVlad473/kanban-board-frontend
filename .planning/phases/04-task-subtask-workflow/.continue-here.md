| Pattern | Description | Severity | Prevention Mechanism |

| A detector shaped for one case, read as proof of absence | The phantom drop zone was reported as "cannot reproduce, hypothesis falsified" after a live drag probe. The user's screenshot settled it. | blocking | Before concluding a thing is absent, prove the detector finds it in a state where it MUST be present. Run a positive control every time. |

The test passed against the UNFIXED code, proving `resetField` already clears errors.
