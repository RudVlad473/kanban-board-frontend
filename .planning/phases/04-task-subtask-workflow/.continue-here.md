# BLOCKING CONSTRAINTS — Read Before Anything Else

> These are not suggestions. Each was discovered through actual failure.

- [ ] CONSTRAINT: **One working tree, one agent.** File-disjoint agents still share one git index
      and one pre-commit hook, so each hook run sweeps the others' half-finished work and agents
      "resolve" it with `--no-verify`. Two `comments:check` failures reached this branch that way.
      Structural mitigation: worktrees are FORCED OFF for this phase, so dispatch strictly one
      executor at a time. Never accept `--no-verify`.
- [ ] CONSTRAINT: **A single green LOCAL suite is not sign-off, and local cannot see visual or
      e2e at all.** `playwright.config.ts` sets `ignoreSnapshots: !process.env.CI`, so every local
      `toHaveScreenshot` is a silent no-op; and local e2e is forbidden mid-wave because it wipes the
      shared backend. So the local gate is structurally blind to exactly two job types — and that is
      where `daaf5fa` went red. Structural mitigation: **CI is the sign-off**; a wave is not closed
      until `gh run view` shows all four jobs green.

**Do not proceed until both boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Concurrent agents in one checkout | File-disjoint agents share the git index and pre-commit hook and bypass it to get their own files in | blocking | One worktree per agent, or strict serialisation. Worktrees are forced off here, so serialise. `--no-verify` is never the answer |
| Writing an e2e spec without executing it | 04-20 wrote `tasks-delete.e2e.spec.ts`, type-checked it, ran `--list` on it, and shipped it. It has 2 real failures. `--list` proves collection, NOT that a test passes | blocking | A spec that has never been executed is unverified regardless of how much static checking it survived. Run it, or state plainly that it is unrun |
| Deferring CI while local is the only gate | Per-wave CI watching was dropped for speed; `daaf5fa`'s red e2e job then went unnoticed for a whole wave | advisory | The `gh run list` glance costs ~2s and is not the slow part. Never skip the glance, even when skipping the watch |
| Stale plan prose outliving a refactor | Phase-04 plans instructed executors to build ADR 0029 machinery deleted in `3089a6a`, including reading `rename-override-provider.tsx`, which no longer exists | advisory | Corrected in `4240136` for 04-18/19/20. If a plan disagrees with an ADR, the ADR wins — say so rather than building it |
| Trusting an executor's own green claim | Executors have reported green while wrong; one truncated final message looked like a stall while the work had completed | advisory | Orchestrator re-runs the gate itself. It caught a red `comments:check` on the orchestrator's own comment |
| Trusting a bug-fix test without a negative control | A test that passes both with and without the fix is worse than none | advisory | Revert only the fix, run the test, confirm it FAILS, restore. Done for 04-20's key collision: 54 tests fail without it |
| zsh eats backticks and `:check` | An unquoted backtick in a heredoc-free script is a parse error that kills the WHOLE script, so an earlier `git checkout` silently never ran | advisory | Brace `pnpm "${s}:check"`; avoid backticks in `grep -E`; re-verify that restore/cleanup commands actually executed |
