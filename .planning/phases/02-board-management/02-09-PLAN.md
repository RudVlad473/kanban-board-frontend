## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-02-39 | Information Disclosure | Collapse state persisted to a cookie or localStorage | low | mitigate | DEFAULTS.md C-009 locks this to non-persisted `useState`. Task 2's behavior block requires an accessible `Show Sidebar` control in the collapsed state and asserts keyboard reachability for both controls. |
