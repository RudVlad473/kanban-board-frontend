## Findings

### 1. Selected Board row does not reach the page edge

The selected Board pill (`newnewnew` in the screenshot) is inset from the left edge of the
viewport — there is a visible gap between the window edge and the start of the highlighted pill.
The reference design runs the selected row full-bleed to the sidebar's left edge, rounding only
the right end into a pill. Check `board-list.tsx` / `sidebar.tsx` horizontal padding: the
selected background appears to be inside the container padding rather than the row spanning the
full width with the padding applied to its contents.

### 2. No icon before a Board name

Every Board row is text only. The reference design places a board/columns glyph immediately
before each Board name, in the same colour as the label, switching to the active colour on the
selected row. No icon is rendered for any row.

### 3. "Create New Board" needs an icon too

The create-Board control must carry a leading icon in the same position and size as the
per-Board icon from finding 2, so the control reads as the last item in the same list rather
than as unrelated text. Note: the create control is not visible at all in the supplied screenshot
— confirm whether it is below the fold, or missing from the rendered sidebar, before styling it.

### 4. Theme toggle does not match the mocks

The theme toggle does not look like the reference design. Not visible in the supplied screenshot
(expected at the sidebar's lower region), so the specific deltas are not yet enumerated — needs a
side-by-side against the mock before any fix. See `02-UI-SPEC.md`.

## Resolution (2026-08-25)

Closed as a fix commit on 02-10 (per user decision). All four findings fixed and diagnosed against
the canonical design source (`docs/kanban-task-management-web-app.pdf`, pages 2/12):

1. **Full-bleed selected row** — fixed in `69f642a`. Horizontal padding moved off `<ul>`/`<li>`
   onto the row's own `Link`; `rounded-r-lg` → `rounded-r-full`.
2. **Board-row icon** — fixed in `a1a9ccb`. `lucide-react`'s `PanelLeft` (confirmed against the
   icon's own source vs. `Columns2` — `PanelLeft`'s divider is off-center, matching the mock).
3. **"Create New Board" icon** — confirmed it was genuinely not rendered (no icon markup existed
   at all); fixed in the same commit as finding 2, same icon.
4. **Theme toggle** — fixed in `b703923`. Root cause: icons were rendered inside the `Switch`
   thumb instead of as static flanking icons; rebuilt into a `bg-bg-app rounded-lg` container with
   static Sun/Moon icons either side of a plain switch track, matching both light and dark mocks.

Live-re-verified by the orchestrator via Playwright against the running dev server (signed-in
session, 3 real boards, both themes) on 2026-08-25 — see `02-10-SUMMARY.md`'s "UAT fix-up" section.
