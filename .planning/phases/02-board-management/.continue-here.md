## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Task-notification `status="failed"` does not mean the agent process actually stopped | Twice this session an executor's mid-response API connection drop produced a `status="failed"` notification while the underlying agent kept running in the background and committed more work afterward. Recovering (merging its worktree) while it was still alive risked racing a live agent. | advisory | Before treating a `failed` notification as terminal and recovering/tearing down its worktree: check `ListAgents` for that agent id. If it still shows `running`, wait for the real completion notification instead of racing recovery against it. (Now also logged in the global `~/.claude/TOOL_GOTCHAS.md`.) |
| Bash tool's cwd persists across calls, including into a git worktree after a manual `cd` | Debugging inside an executor's worktree (`cd .claude/worktrees/agent-.../`) left the Bash tool's shell sitting there for subsequent calls. A later `Edit` meant for the main checkout (`deferred-items.md`) tripped a worktree-path guard because the shell's cwd — not the file's own path — was still the worktree. | advisory | Explicitly `cd` back to the main repo root (or re-derive it via `git rev-parse --show-toplevel`) before any file operation that assumes the main checkout, right after finishing worktree-scoped debugging. |
| This project has TWO Playwright MCP integrations, only one of them headless | `.mcp.json` configures a project-scoped `playwright` server (headless), but it only loads after a session restart. A globally-installed `plugin:playwright` integration can also resolve in the same session, has no headless override, and looks identical from the tool name pattern at a glance — using it pops a real visible browser window. | advisory | Before driving any browser tool, confirm the resolved tool names start with `mcp__playwright__` (project's own). If only `mcp__plugin_playwright_playwright__*` resolves, the project's headless server isn't loaded this session — needs a restart. (Now documented in this project's own `CLAUDE.md`.) |

**Severity values:** `blocking` — resuming agent must pass understanding check before proceeding. `advisory` — important context, does not gate resumption.
