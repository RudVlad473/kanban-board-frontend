## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser URL -> Server Component page | A board id typed into the address bar is fully attacker-chosen and reaches both the page's membership check and the server read |
| Next.js server -> external Kanban backend | The server-derived `userId` and the caller's board id cross here together |
| external backend -> server read | The full-board response is a nested untrusted structure whose every field the contract declares optional |
