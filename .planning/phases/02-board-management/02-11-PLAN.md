## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → `GET /api/boards/{boardId}/full` | A boardId in the path is fully attacker-chosen; this is the phase's most direct object-reference surface |
| browser URL → Server Component page | A boardId typed into the address bar reaches the page's own server-side membership check |
| external backend → Route Handler | The full-board response is a nested untrusted structure whose every field the contract declares optional |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-49 | Elevation of Privilege | Insecure direct object reference on `/api/boards/{boardId}/full` | critical | mitigate | The handler sends the session's own `userId` with the caller's `boardId`, so the backend's single-owner scoping (ADR domain/0001) refuses another user's board — the behaviour 02-BACKEND-FACTS.md's P7 observed directly. Task 1 adds a test asserting a client-supplied `userId` is ignored. If P7 recorded that the backend does not enforce ownership, plan 02-06's decision checkpoint escalated it and this endpoint must not ship until resolved. |
| T-02-50 | Information Disclosure | Membership check in `[boardId]/page.tsx` | high | mitigate | The page tests the requested id against the session user's own list before rendering, so a foreign id redirects rather than triggering a fetch whose failure mode might vary. This is defence in depth above the Route Handler's own control, not a replacement for it. |
| T-02-51 | Tampering | Unvalidated nested upstream body rendered as a board | medium | mitigate | `isBoardFull` composes down through `isColumnFull`, `isTaskFull` and the subtask guard; a malformed nested payload becomes a 502 rather than a partially-rendered board with undefined text. | T-02-52 | Elevation of Privilege | `boards-server-api.ts` reaching a client bundle | high | mitigate | The module carries `import "server-only"` on line 1 and no barrel exists in its folder to launder an import through. Asserted by greps in Task 1 and structurally by `pnpm build`. |
| T-02-53 | Spoofing | Auto-select redirect masking which board is shown | medium | mitigate | The redirect changes the URL rather than silently rendering a substitute at the requested address, so the user can always see which board they are actually looking at. | T-02-54 | Information Disclosure | Board, column and task names rendered in the view | low | accept | React escapes JSX text nodes and no `dangerouslySetInnerHTML` exists in this codebase; the view renders every name as a text node. |
