<objective>
Collapse the two TanStack Query cache keys — currently declared across three places, one of them
inside a feature folder — into a single `QUERY_KEY` declaration in `src/lib/core/query-keys/`,
mirroring the shipped `MUTATION_KEY` pattern, and add a gate that keeps them there.

Purpose: `["boards"]` lives in `src/features/boards/queries/boards-query.ts` while its sibling
mutation keys live in `src/lib/core/query-keys/mutation-keys.ts`, and `["board"]` is spelled twice
inside `board-query-key.ts` itself. One declaration removes both drift seams.

Output: a `QUERY_KEY` module, every call site migrated, and a `keys:check` gate wired into
`pnpm verify`, `pnpm gates:check` and CI together.

**This is a PURE REFACTOR.** No behavior change, no key-string change, no new runtime logic. A
changed key string is a failed refactor, not a variation.
</objective>
